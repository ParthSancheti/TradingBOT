    Connect your business workbook

    Business records stay in Google Sheets. API keys and signing secrets stay in your OS credential store.

    1. Create an Apps Script project in your Google account. Add the two files below and the manifest.
    2. In Project settings → Script properties, add JARVIS_SIGNING_SECRET with a new random secret of at least 32 characters. Do not put it in a sheet cell.
    3. Run setupJarvisWorkbook once and authorize the spreadsheet access. It creates the workbook or uses JARVIS_SPREADSHEET_ID if you set it.
    4. Deploy as a web app executing as you. Every data request must have the signing proof. Copy the deployed /exec URL.

    Start your WhatsApp desk

    1. Build and install the native desktop helper once using the packaged instructions.
    2. In Chrome → Extensions → Manage extensions, load the supplied extension folder. Register its exact ID with the helper.
    3. Click Start below, sign in to WhatsApp if necessary, then use Start observation in the extension popup.
    4. Keep this computer running. Each minute starts a bounded source scan; the screen reports actual coverage and failures.
